## 🔍 Что такое Float (износ)?

**Float** — это числовое значение от 0 до 1, которое определяет визуальное состояние скина в CS2. Чем ниже значение, тем лучше выглядит скин.

| Категория | Диапазон Float | Описание |
|-----------|---------------|----------|
| **Factory New (FN)** | 0.00 – 0.07 | Идеальное состояние, самая высокая цена |
| **Minimal Wear (MW)** | 0.07 – 0.15 | Незначительные потёртости |
| **Field-Tested (FT)** | 0.15 – 0.38 | Заметные следы использования |
| **Well-Worn (WW)** | 0.38 – 0.45 | Сильный износ |
| **Battle-Scarred (BS)** | 0.45 – 1.00 | Максимальный износ, самая низкая цена |

На нашем сайте вы можете фильтровать скины по Float, чтобы найти идеальный вариант.
